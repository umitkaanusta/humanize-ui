# Examples

These examples use the same brief to compare a typical generated landing
page against one made with the `humanize-ui` skill, this time for a software
business.

![Before and after comparison of the BeaconOps landing page](before-after.png)

## Prompt Without `humanize-ui`

```text
Create a brief static landing page for an incident monitoring software
business called BeaconOps.

Requirements:
- Output a single HTML file with CSS inside a <style> tag.
- Include a hero, 3 product benefits, a simple pricing strip, and a final CTA.
- Make it responsive for mobile and desktop.
- Treat the page like a real B2B software product: inspect the brief, choose
  a concrete product direction, show a software-specific visual system, polish
  spacing, hierarchy, color, copy, interaction states, and responsive behavior.
```

Output file:

- `landing-page-without-humanize-ui.html`
